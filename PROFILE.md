# WealthVille — DeFi Liquidity Pool Scores API (Solana & EVM)

WealthVille provides a public, keyless REST API and agent-native surfaces for DeFi liquidity-pool scoring and signals across Solana and EVM chains. It exposes a composite Wealthville Score (0-100) with Enter/Hold/Exit verdicts, per-protocol confidence, Solana sub-scores (Risk, Scout, Farmer), an outcome-labeled track record, and a signals feed. Coverage includes Solana (Meteora, Orca, Raydium) and EVM chains (Ethereum, Arbitrum, Base, Optimism, Polygon, BNB Chain).

## APIs

- **WealthVille Public Scores & Signals API** — Public, keyless REST API for DeFi liquidity-pool scores, verdicts, track record, and signals feed. Anonymous access at 60 req/min per IP; optional free partner keys via x-api-key header. CORS-open. (`https://wealthville.net`)

> REST API is public, keyless (60 req/min per IP, optional free x-api-key partner keys), CORS-open, with endpoints under https://wealthville.net/api/v1/ (scores/top, scores/{poolAddress}, track-record, signals/feed). An OpenAPI contract is advertised at https://wealthville.net/api/v1/openapi.json but could not be directly confirmed reachable during research, so it is not cataloged as a property; recommend a manual GET before publishing an OpenAPI flag. The MCP server (@wealthville/mcp-server) is a LOCAL stdio server run via npx (claude mcp add wealthville -- npx -y @wealthville/mcp-server), NOT a hosted HTTP endpoint — https://wealthville.net/mcp is only a documentation/install page, so no MCP property is emitted. Agent-native status is driven by the confirmed live llms.txt (https://wealthville.net/llms.txt) plus published npm plugins (Solana Agent Kit plugin @wealthville/solana-agent-kit-plugin and ElizaOS plugin @wealthville/plugin-wealthville, source at github.com/amitesh-m/wealthville-integrations). API/data is free with attribution.
